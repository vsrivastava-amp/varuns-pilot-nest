# Suggested title: Investigate model-serving path for online pCIV: prompt caching and provider region
# Links: relates to AI-1588 (latency optimization), AI-1542 (latency testing), AI-1540 (model choice)

Two open questions about how we serve the model for online pCIV. Both affect latency and cost, and both feed the lever set in AI-1588.

*Prompt caching*
* Does Bedrock/Mantle implicit caching discount price, or only latency? Gemma 4 31B is the cheapest thing to check against — Cost Explorer line items after the 2026-07-28 screen run should show it.
* Caching only hits on byte-identical prefixes above ~1024 tokens. If it is worth having, the prompt needs a fixed instruction + taxonomy block first and the dynamic query last. That is a constraint on prompt design, so the answer needs to reach Yaarit (AI-1576) before the prompt settles.

*Provider region*
* Our current baseline (gpt-5.4-nano) is served via Databricks, out of network. Check whether OpenAI direct offers us-east serving, and what that would do to the network hop.

Outcome: a short recommendation on caching and serving region, feeding AI-1588 and the model decision.
