AI-1474 reclassifies the keyword set once. Its scope line anticipates the rest — "eventually: set up a pipeline to ensure that keyword classification is not just one time" — and Dhaval has asked for a regular cadence.

Keywords in `prod_amplify.dsp.audience_keyword_targeting` turn over, so a one-time pass goes stale. This ticket covers making reclassification recurring rather than manual.

Open questions for grooming:
* What cadence, and is it time-based or triggered by new-keyword volume?
* Does it reclassify everything, or only keywords not already categorized?
* Which model, and does that decision re-open each run or stay pinned?

Note a known footgun for whatever runs this: the classification cache keys on eval ID plus normalized query, and there is no blanket purge in the service API. Reusing an eval ID can silently serve results from a previous model.
